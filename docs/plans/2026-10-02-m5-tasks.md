## 2. 结构决策与 why

- **README 的 demo 用"脚本 + 实际输出"**：token 瀑布是 M1 旗舰的记忆点（01 §6），README 里放 only-context 的真实输出片段，不截图不编造。
- **publish.yml 只负责"机械动作"**：由所有者推 tag 触发，PyPI 用 trusted publishing（无需长期密钥）；工作流内注释写明"发布决定权在所有者"——机器永远不主动发。
- **占位清单（07 §3）是所有者动作**：GitHub org / PyPI 包名占位 / 域名 / 社交 ID——仓库侧能做的（元数据、URL 指向 github.com/Ember452/tutelary）本阶段做掉，账号类动作列清单移交。
- **CHANGELOG 从 0.1.0 起笔**：lockstep（ADR-0003）——一个版本节覆盖全部发行包，按里程碑叙事。
- **deep-dive 是文档不是博客**：落在 `docs/deep-dive/`，与设计文档同库同审，示例代码与实现同源。
