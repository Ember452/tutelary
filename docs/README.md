# Tutelary 文档

> **Tutelary** /ˈtjuːtələri/，"护法的"——tutelary deity，护法神。
> 本项目是治理优先的 Agent 运行时基础设施：像护法神守着修行者一样，守着 Agent 的预算、权限、隔离与记忆。

一句话定位：**可拆解的 Agent 基础设施——每个组件独立安装、独立可用、独立发布，一个只做装配的薄内核把它们缝起来。**
